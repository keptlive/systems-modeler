Stock & Flow is a visual systems dynamics workspace. Start with a library example, draw a system yourself, or ask the AI assistant for a draft. Inspect the assumptions, run the model, and compare what changes when parameters change.

Library entries are examples with varying levels of completeness. A completed numerical run does not establish scientific validity. Inspect initial values, equations, units and original references before interpreting the results. Failed runs report diagnostics; equations are never silently replaced with zero.

Start in the browser

Bring your own agent. Choose Connect agent to connect this page to your agent through MCP. Your agent authors and interprets the model; no server-side AI account is required. Existing manual editing and optional server AI remain available.

  1. Open the editor and choose Model Library. Search for Bank Balance with Compound Interest for a simple example. Expand a result to inspect its equations, then select Import.
  2. Select a stock, flow or variable on the diagram to edit its properties. Stocks accumulate quantities; flows change stocks per unit time; variables express parameters and calculations. Connectors show dependencies.
  3. Open Settings. Use Check inputs to inspect initial values, references and connections. The toolbar’s Inspect button opens the same report directly. Search equations, select an element to edit it, or choose Investigate numerical behavior to compare the full horizon at the current, half and quarter time steps. Download the evidence report without changing the model. Choose start, end, time step and Euler or Runge–Kutta 4, then Apply & Run. Smaller steps can improve accuracy but require more computation. Compare runs at smaller steps before trusting a trajectory.
  4. Inspect Chart and Analytics. Existing line, area, stacked, phase, logarithmic, normalization, animation, comparison and saved-run controls remain available. AI Insights uses the configured provider when available.
  5. Use Save for your edited copy. My Models lists models saved in this browser. JSON export retains the full model; XMILE exports the supported scalar subset. Keep an exported copy for portability.

On smaller screens, the toolbar and AI, Edit and Results panels expose the same model. The separate library has category browsing, search, Simulate deep links, and JSON/XMILE downloads.

Understand a simulation

Analytics describes the recorded samples. Time-weighted means account for irregular spacing. Patterns and tail stability are qualified heuristics; raw variance comparison does not measure causal influence or parameter sensitivity. Undefined constant-series correlations are omitted, and any correlation coverage limit is reported. AI interpretation is labeled separately from statistical fallback.

Euler advances using rates at the beginning of each interval. RK4 combines four derivative evaluations per interval. Settings are honored explicitly, including a nonzero start time. The final stop time is included with a shorter last interval if necessary. Recorded variables and flows correspond to the recorded stock state and time.

STEP, PULSE and RAMP, including their arguments, are evaluated at accepted simulation times and held over the following timestep for both methods. Other time-dependent equations retain normal stage evaluation. Reduce the time step to resolve off-grid events. PULSE(magnitude, first_time[, interval]) uses the XMILE magnitude signature, not Vensim’s start/width signature. A held ramp has first-order forcing accuracy even with RK4.

Smoothing and fixed-duration material delays support Euler and RK4. Fixed history delays and random functions require Euler; unsupported combinations are rejected explicitly. Set an optional integer random seed in Settings to repeat a stochastic run. The effective seed is returned with results when one is chosen automatically. A model’s explicit function seed takes precedence for that call. Different time steps do not define a coupled stochastic experiment. A negative stock can indicate an unsuitable time step or a model-domain problem; some quantities are intentionally signed, so the engine does not automatically clamp them.

Runs are limited to 500 elements, 10,000 intervals and 1,000,000 work units (elements, hidden stages and random calls per interval; RK4 charges five evaluations). Increase the time step or narrow the horizon when a run exceeds those bounds. Unknown symbols, circular algebraic dependencies, invalid operations and non-finite values return errors with context.

Connect an MCP client

For a visible working page, call open_workspace and open the private URL it returns. Keep the workspace key private. Inspect, make targeted edits, run, select a view, then confirm the browser applied the revision. Temporary sessions expire after one idle hour or a server restart; Save remains a separate action.

Imports and portability

JSON is the complete native format. Supported XMILE imports include scalar stocks, flows, auxiliaries, initial equations, time settings, graphical functions and diagram positions. Namespace quote styles and reciprocal time steps are understood. The optional run seed round-trips through a Stock & Flow namespace extension; other tools may ignore this extension. Continuous graphical functions clamp outside their range; extrapolating and discrete types retain their declared behavior. Unsupported arrays and nested models are rejected rather than silently discarded.

Model equations may use functions that another modeling tool does not implement. Check numerical agreement after moving a model between tools. See the XMILE specification and the repository tests for the supported subset.
