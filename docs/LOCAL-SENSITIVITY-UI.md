# Additive local sensitivity UI

## Interface baseline recorded before editing

Source inspection2026-10-24, before UI changes: the editor exposes model elements/connections/properties, library import, save/import/export, simulation settings and run controls. The existing Inspect action opens input checks, dimensional findings, issue-to-element navigation, last-run local feedback, complete-horizon timestep investigation, searchable equations/initials, source/settings and report download. Source separately retains original MDL download and JSON preview/apply-to-draft; Save remains separate. Simulation charts, analytics (including explicitly labeled raw variance rather than parameter sensitivity), data/results tabs and fullscreen analysis retain their own state. AI assistant generation/modification remains available. Tuning and scenario comparison are existing backend/API/MCP capabilities; no dedicated current JavaScript tuner/scenario button was found during this inspection. No existing feature is being renamed or removed.

Owned UI integration is a new script include and isolated module. The proposed control is collapsed details inside the existing Inspect dialog, using its captured model/settings snapshot. It does not add a toolbar button, replace variance analytics, run the AI tuner, modify/save parameters, load a model or assign Simulation/Charts/Analytics results. Server admission remains authoritative. Root will perform browser verification and an independent reviewer will review this UI.

HTTP contract coordinated with transport author: POST /api/sensitivity/local with model snapshot, ordered parameters containing immutable variable IDs and positive absolute steps, and output_stock_id. Response is the reviewed scalar core report;422typed admission,429busy and503quota-unavailable failures remain visible. Browser cancellation aborts the request and requests server cancellation; it does not claim that server cleanup has already completed.

## Implemented behavior and verification

The collapsed Inspect section requires explicit stock and numeric constant selections and explicit positive absolute steps. Parameter choices show names, IDs, values and supplied units. Derivative units, unavailable elasticities, refinement/asymmetry warnings, underflow, unresolved resolution, failed perturbations and complete JSON provenance remain visible. The report download is separate from model export. Draft changes invalidate a pending form; changes during a request label the returned report as the inspected snapshot. Close, Cancel and detached panel disposal abort requests, and late responses cannot repopulate cancelled results. A35second client timeout requests cancellation; backend admission retains its own shorter bounded deadline.

`tests/test_local_sensitivity_ui.py` runs a dependency-free Node DOM harness, exercising actual module code: mounting exactly once inside Inspect while retaining its existing investigation section; literal discovery; explicit ID/step payloads and duplicate rejection; snapshot preservation; derivative units, failure and warning rendering; inert user text; unchanged model/simulation state; stale-draft refusal; typed server failures; cancellation, late responses, dialog close and disposal. It passed locally. This is a behavior check, not a visual or accessibility certification. Root's browser verification and independent UI review remain required before release.

Independent UI review found and corrected two presentation gaps. Editing output/parameter/step selections or adding/removing rows now clears the prior table and asks for a new analysis, preventing it from appearing to describe changed form values. The timeout callback now publishes its terminal message immediately even if an aborted fetch later resolves successfully. The Node harness independently drives these mutation and delayed-settlement paths.
