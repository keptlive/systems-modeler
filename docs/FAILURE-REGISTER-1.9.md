# Failure register 1.9

All 47 previously failing definitions were investigated against original sources and independent mathematics. Nineteen repairs now complete; 28 remain unresolved. The full 1,078-model audit has **1,050 completed / 28 failed**, with no previously completing model regressing.

The [machine-readable register](../operations/failure-register-v19.json) binds every case to exact baseline/current hashes, its source receipt, causal explanation and independent checks. The [full audit](../operations/library-full-v190.json) binds all model files and current engine files. Source-partition probes retain their actual historical engine fingerprints; the full audit is the final release fingerprint.

A passing simulation is not proof of calibration. Repairs include faithful native reconstructions, explicitly bounded source adaptations, a solver correction and an engine reporting feature. Their differences from the earlier generated models are archived rather than concealed.
