# Biology library review candidates

## Admission update — October 24, 2026

All ten examples are now admitted after independent numerical and source review. Exact source bytes, approval hashes and destinations are recorded in `operations/library-admissions-20261024.json`. The preparation notes below describe the earlier candidate stage. Deployment status is recorded separately; admission is not empirical certification.

Ten source-attributed dynamic examples are prepared under `operations/library-candidates-biology/`. They are **review candidates only**. No active library file, deployed definition or user model has been replaced. The current 923-model inventory and retirement manifest were read before selection. The retired Goodwin, repressilator, glycolytic, Gierer–Meinhardt and Droop entries were flowless stubs; these are newly transcribed dynamical systems with independent checks, not restored placeholders.

All ten include explicit state units, parameter units, time units, initial values, defaults, assumptions and primary references. All pass native dimensional analysis and complete their default horizons. Signed net-rate flows encode ODE derivatives; they do not claim that arrows establish physical transport or that distinct species can be equated. No MIN/MAX domain clamps, arbitrary damping corrections or zero-flow placeholders were added. Eight are continuous ODE examples and two are explicitly discrete recurrences, with `discrete_period=1` and Euler restricted to exact generation/census updates.

## Independent admission evidence

`tests/test_library_candidates_biology.py` contains **29 passing tests**. For all eight continuous models, handwritten numeric right-hand sides are integrated independently with SciPy DOP853 (`rtol=2e-11`, `atol=2e-13`) and compared at every retained default time. The reference functions do not read model expressions or parameters, so they can expose transcription mistakes. Largest scaled discrepancy `abs(actual-reference)/(1+abs(reference))` is approximately5.56e-7 across this batch; the exact per-model values and file hashes are saved in `operations/library-candidates-biology/evidence/validation.json`.

Four RK4 examples also show decreasing error under half-step refinement. Discrete models match every independently computed matrix power/recurrence, not an ODE interpolation. Additional checks cover positive domains, changing states, internal nutrient conservation, the quota floor as a mathematical invariant, mitotic enzyme fractions in[0,1], repeated mitotic cycles, source-based stationary states, nonlinear switch equilibrium/ultrasensitivity, and the Nicholson–Bailey unstable equilibrium.

The initial coarse fixed-step repressilator failed the independent reference check and was changed to adaptive Radau; tolerances were not relaxed to admit it. The covalent-switch horizon was extended from100 to300 because the shorter run had not reached its analytic steady state. These numerical choices do not imply biological calibration, field validation or predictive accuracy. Illustrative defaults are identified as such in each saved description and manifest.
