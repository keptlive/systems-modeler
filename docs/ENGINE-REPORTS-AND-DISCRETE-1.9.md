# Explicit reports and discrete recurrences

Variables default to `role: "auxiliary"`. A `role: "report"` variable is a read-only output evaluated at each retained time after numerical integration. Its result can be a finite number or a single-quoted text label. Double quotes retain their existing XMILE identifier meaning. Nested IF/IF_THEN_ELSE branches are lazy. Text cannot enter arithmetic or a condition. Conditions use actual floating-point results with no threshold snapping.

Reports may reference numeric elements, TIME, DT and tables. Reports cannot feed any equation (including another report), even in an inactive branch. Random and stateful calls are rejected throughout report expressions. A label is limited to 512 characters, and the worst-case retained label budget is one million characters. Reports count against the 500-element and one-million retained-value limits; their evaluation work is reserved in the combined integration work budget. Numeric placeholders preserve accounting but are never returned.

REST returns report series in `report_values`, separate from numeric `values`. MCP `simulate_model` samples report series at exactly the same indices as numeric data. Numeric statistics and charts therefore remain numeric. Desktop and mobile results show final report outputs. The properties editor exposes the role, and JSON save/import/export preserves it. XMILE export rejects reports explicitly rather than silently discarding the role or coercing text to zero.

The Limits to Growth teaching model's original System State expression is preserved verbatim. Its status output now has the explicit report role. Its two-state equations and parameters are unchanged; independent RHS integration and Euler refinement check their implementation. This is a qualitative teaching scenario, not an empirical reproduction of a quantified model from Senge's book.

`time_settings.discrete_period` optionally declares a fixed-period difference model. Such a model must use Euler with DT equal to the declared period and a duration containing a whole number of periods. The stored model contract also applies to simulation/validation/investigation overrides. A derivative-shaped flow represents the change per unit time necessary for that declared recurrence; it is not assumed to define a continuous ODE. JSON preserves the declaration; XMILE export rejects it. Settings show the fixed method/cadence, and investigation does not perform meaningless half/quarter-period refinements.

Tests exercise report isolation, lazy branches, name aliases, inactive-branch feedback rejection, typed API/MCP output, capacity limits, all three solvers, exact recurrence, bypass attempts through request overrides, and independent dynamics. These capabilities do not establish scientific validity for arbitrary submitted equations.
