## Verification, independence and bounds

`python -m pytest -q tests/test_library_candidates_environment.py` completes with **26 passed** (about6seconds in this session). All ten full default trajectories are compared, at every saved time, to independently handwritten numerical right-hand sides integrated with tight SciPy DOP853 (`rtol=2e-11`, `atol=1e-14`). Reference code does not evaluate saved model expressions or read their parameters. Row-wise tolerance combines relative error3e-6 with an amplitude-scaled absolute floor1e-8; this handles genuine velocity zero crossings without an ill-conditioned pointwise relative error. Additional closed-form/invariant checks are stricter where available.

Four fixed-step examples also show reduced independent-reference error when the timestep is halved. Tests include the Green–Ampt implicit integral, exact oxygen sag/critical time, the homogeneous vegetation fixed point/water-use identity, independent competitive-sorption equilibrium and two solute totals, geometric dissolution mass conservation/partial-saturation radius, exact cosmogenic production/decay, isotope-lineage matrix exponentials, Ekman column-momentum and energy identities, the ice invariant interval and the aquifer storage/recharge/discharge budget. Not every physically different parameter choice is admissible; no clamp masks invalid assumptions.

Native dimensional analysis is `consistent` for all ten under their declared units. All default state trajectories change and stay finite; positive-domain states remain nonnegative and signed velocities remain available. The adaptive Green–Ampt example retains the canonical engine work diagnostics. Staging evidence, exact JSON hashes, elapsed times, final states and full-reference maximum errors are recorded in `operations/library-candidates-environment/evidence/validation.json`. The largest observed reference error divided by each state's maximum absolute reference value is approximately1.93e-7, in competitive sorption. These are numerical accuracy observations, not scientific uncertainty estimates.

Duplicate screening covered names and process terms across the923 active definitions, direct equation inspection of the closest ice/groundwater/oxygen examples, and conservative normalized stock-derivative AST fingerprints with numeric parameter substitution. No same mechanism/equation definition was found. The existing groundwater examples use scalar storage/recharge/pumping laws, the ice definitions use temperature-driven melting/discharge, and ocean deoxygenation uses temperature/stratification proxies; these are not the equations staged here. Fingerprints are only a screening aid and do not establish general algebraic inequivalence.
