# Independent trust review 1.4

Reviewed 2026-10-20 against the live working tree. This is a bounded review of source warnings, numerical evidence and import loss, not scientific certification of the library. No model, engine or registry changes were made by this reviewer.

## Findings requiring follow-up

1. **Numerical fixtures need reproducible provenance.** `tests/fixtures/math-models-v14.json` names SciPy/DOP853 and tolerances, but does not supply a checked-in regeneration program with explicit independent RHS equations, parameter values and source equation/page mapping. Preserve that program and the dependency version, then regenerate and compare the fixture. Solver independence establishes numerical agreement with a chosen ODE; it does not establish that the ODE faithfully represents a cited paper.
2. **Fixture time is not checked.** `test_compartment_trajectories_against_independent_dop853` uses index `k*128` without asserting the corresponding fixture time. Add `assert result.time[k*128] == pytest.approx(expected['time'][k])` and shape checks. Current grids happen to align; the test would not detect a later incorrect fixture time array.
3. **Default accuracy is under-specified.** The default/refinement test asserts only endpoint-error improvement, without an absolute/relative accuracy threshold or peak/trajectory comparison. Epidemic tails can agree while peak height/time differs materially. Compare the entire default trajectory to independent dense output, report maximum stock-scaled error and peak errors, and set explicit educational-use tolerances. Existing refined RK4 agreement and invariants are meaningful but do not measure default-grid accuracy throughout the outbreak.
4. **Warnings are bounded evidence, not a complete citation screen.** Exact source/reference matching correctly survives equation edits and avoids claiming corrected equations authenticate a citation. Whitespace or DOI spelling changes end the match. The returned `scientific_validation: not established` is essential; absence of a warning must never be labeled source verified. Consider conservative DOI normalization while retaining exact reference identity. No present claim of comprehensive screening was found in the implementation.
5. **Historical failure metadata is not a fresh simulation result.** `audit_sources.py` reads failed paths from a supplied audit but hashes current definitions. Therefore `default_error` may be an old error attached to new bytes. Store the input audit hash/path and original audited definition hash separately, mark errors historical, and record retrieval timestamps/cache provenance. The existing scope and meaning text correctly limit the report to bibliographic metadata, but the mixed-time fields need care in consumers.

## Importer investigation

A read-only search of current Python/JavaScript sources found no general Vensim `.mdl` importer; `static/js/xmile-import.js` handles XML, and `scripts/investigate_models.py` fetches specific historical source examples. Thus no current importer function can responsibly be patched on this evidence. The first-definition losses and flow misclassification documented in SOURCE-REPAIRS-1.4 are consistent with historical extraction defects; the exact historical parser mechanism remains unproven.

For a recovered or newly implemented Vensim importer: remove only an anchored optional BOM/`{UTF-8}` header before tokenizing the first record; never discard the entire first `|`-terminated record to skip encoding metadata. Parse INTEG expressions into signed flow incidence: named positive terms become inflows and named negative terms outflows, with shared transfers linked to both stocks. Do not infer flow type solely from diagram glyphs or equation ordering. Reject unsupported compound/dynamic stock derivatives explicitly instead of silently converting them to auxiliaries. Regressions must include a header followed immediately by a first definition, no header, BOM+header, a stock with two inflows and two outflows, a shared transfer, and named first definitions AIR/Depreciation/Emissions. Verify semantic element counts and source names, not just successful execution.
