Repairs bind incomplete identifiers to uniquely identifiable existing nodes. These are import/definition repairs, not a claim that a generic repository or textbook cited by the old file supports its equations. Partial repairs retain missing-input errors, nonlinear divergence, algebraic cycles and domain errors. No guessed constants, arbitrary clamps, altered timesteps, removed nodes or suppressed errors were used.

Oregonator lacks all RHS equations; raising the work limit merely exposes a constant-stock false pass.

Those misattributions were withdrawn or corrected. Correct contextual references do not establish the local numerical model.
