# Reviewed model admissions — October 2026

The public source library contains 1000 models: 997 dynamic examples and three explicitly static calculators. Six batches add 84 independently reviewed examples to the 923-model curated baseline. Source-quality reviews retire seven unsupported or redundant definitions in total, including two May parameter variants, and replace reviewed canonical examples: 923 + 84 - 7 = 1000. The 26 later citation corrections change descriptions only. Historical admissions, the earlier five quality retirements and the original 155 retirements retain their exact evidence and archives. Model count does not justify duplicates, unsupported equations or nominal variations. Local source adoption is separate from public deployment; see the May migration document and quality-follow-up manifest.

The additions comprise five mechanistic numerical benchmarks, twenty biological systems, thirty-one feedback/control examples, ten environmental process-law adaptations, fourteen further physical/scientific examples, two ecological/adsorption systems and two finite-state/control systems. Each admitted file is an exact copy of its independently reviewed candidate, with a SHA-256 approval and source path in `operations/library-admissions-20261024.json`. The second twenty are separately recorded in `operations/library-admissions-second-20261024.json`. Candidate source, license notices, numerical evidence and independent review are retained alongside each batch. Admission tests enforce exact bytes and IDs, and cross-batch duplicate checks exclude only the candidate being checked.

The numerical checks use handwritten independent derivatives, SciPy reference solvers, matrix exponentials, exact recurrences, analytic equilibria, conservation identities and step refinement where applicable. These tests check the described mathematics and implementation; they do not establish empirical accuracy or suitability for forecasting. Illustrative parameters, simplified closures, inaccessible original sources and incomplete unit metadata remain disclosed in the batch documentation.

Five short chaotic/neural examples remain outside the active library: their current brief transients do not add enough demonstrated value. The retained examples include heavy stiff systems and a seven-body gravitational problem; users should expect different runtimes. All default runs must pass the full-library audit before release. Source counts describe the checked-in library, not private user definitions on a running deployment.
