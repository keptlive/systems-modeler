# Reviewed model admissions — October 2026

The public source library contains 995 models: 992 dynamic examples and three explicitly static calculators. Three batches add 77 independently reviewed examples to the 923-model curated baseline. A subsequent source-quality review retires five unsupported or redundant definitions and replaces one canonical capital-sector example, leaving 995 active examples. The earlier 155 retirements and their original regression fixtures remain intact. The target of 1,000 does not justify admitting duplicates, unsupported equations or nominal variations.

The additions comprise five mechanistic numerical benchmarks, twenty biological systems, thirty-one feedback/control examples, ten environmental process-law adaptations and eleven further physical/scientific examples. Each admitted file is an exact copy of its independently reviewed candidate, with a SHA-256 approval and source path in `operations/library-admissions-20261024.json`. The second twenty are separately recorded in `operations/library-admissions-second-20261024.json`. Candidate source, license notices, numerical evidence and independent review are retained alongside each batch. Admission tests enforce exact bytes and IDs, and cross-batch duplicate checks exclude only the candidate being checked.

The numerical checks use handwritten independent derivatives, SciPy reference solvers, matrix exponentials, exact recurrences, analytic equilibria, conservation identities and step refinement where applicable. These tests check the described mathematics and implementation; they do not establish empirical accuracy or suitability for forecasting. Illustrative parameters, simplified closures, inaccessible original sources and incomplete unit metadata remain disclosed in the batch documentation.

Five short chaotic/neural examples remain outside the active library: their current brief transients do not add enough demonstrated value. The retained examples include heavy stiff systems and a seven-body gravitational problem; users should expect different runtimes. All default runs must pass the full-library audit before release. Source counts describe the checked-in library, not private user definitions on a running deployment.

Batch evidence: [mechanistic](LIBRARY-CANDIDATES.md), [biology](LIBRARY-CANDIDATES-BIOLOGY.md), [applied control](LIBRARY-CANDIDATES-APPLIED.md), [environment](LIBRARY-CANDIDATES-ENVIRONMENT.md). The historical curation manifest is unchanged; the admissions manifest extends it explicitly.


The final batch and quality actions are recorded in `operations/library-admissions-third-20261024.json` and `operations/library-quality-20261024.json`. Five retired definitions and the replaced original remain byte-exact regression fixtures. The quality review takes priority over reaching exactly 1,000; finite execution alone did not justify their scientific claims.
