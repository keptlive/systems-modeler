# Corpus repairs 1.9 — source partition A

Six of the sixteen assigned failures now complete their full saved horizons with source equations or a documented source adaptation. Ten remain explicit failures. The work preserves every previous element ID and position and every original start/end time; restored queues, physical transfers and source parameters are added explicitly. No runtime files were changed by this partition.

The [portable receipt](../operations/corpus-repairs-v19-a.json) contains the exact baseline `3597bbc` text, before/after SHA256, a field-by-field diff, original failure, source reading evidence, full-horizon runs and applicable refinement probes and remaining limitations for every case. The [source fixture](../tests/fixtures/corpus-v19-a-sources.json) pins native files by revision or content hash and includes the actual lookup/irradiance data. The [independent tests](../tests/test_corpus_repairs_v19_a.py) use hardcoded right-hand sides, a matrix exponential and a weekly board-game replay; they do not use the application's expression evaluator for their reference dynamics.
