## Numerical checks and resource limits

The scoped suite has26 tests. Every candidate is compared at every retained time with a separately handwritten numerical right-hand side. LSODA provides the stiff references for Tyson/Vilar; DOP853 provides the others. Reference code does not evaluate the saved expressions or read their coefficients. Analytic solutions, polynomial equilibria, moiety conservation, invariant boundaries and controlled parameter changes provide independent behavioral checks beyond solver agreement. Four selected RK4 systems also show decreasing error when a deliberately coarser verification grid is halved; these probes stay above the reference solver's error floor.

All default models complete inside the unchanged engine work limits. Recorded adaptive work is325542 for Tyson,826056 for Vilar and451537 for the immune model; remaining examples use fixed RK4. The maximum state-amplitude-normalized full-grid discrepancy is approximately1.28e-6, in the inhibited-enzyme transient. Exact measurements and hashes are retained in the evidence file. A finite trajectory and dimensional consistency do not establish scientific validity or calibration.

The original100h Vilar scenario exceeded the work cap at tight tolerances; the retained60h scenario and documented tolerances preserve the complete nine-state source mechanism while staying within the cap. The immune example initially disagreed in a long, extremely small tumor tail because absolute tolerances were too large. Tightening both the engine and independent reference absolute tolerances resolved that disagreement; no population clamps or resets were introduced. Such limits must be rechecked when extending horizons or changing settings.

Tests screen exact identities/names/equation sets and conservative expanded stock-derivative AST fingerprints against active and staged definitions. This is supplemented by the mechanism comparisons above. It is not a proof of non-equivalence under every possible algebraic transformation, state reordering or reparameterization. In particular, no extra toggle or generic predator-prey variant was added.
