# Independent source review of partition A, v1.9

Reviewed the six reconstructed A definitions, their field changes, source fixture and independent tests. No blocking equation-mapping defect was found. This assessment concerns the declared reduced experiments; it does not validate forecasts or claim complete replication of the original research systems.

| Definition | Independent source check | Assessment |
|---|---|---|
| Global carbon | Read the [PennState original equation blocks and coupling instructions](https://personal.ems.psu.edu/~dmb53/DaveSTELLA/Carbon/c_cycle_models.htm), especially simple terrestrial equations, simple ocean equations, TC4 and GC1. Checked the carbonate quadratic root, alkalinity relation, 12000/0.0363 carbon conversion, 280 pCO₂ factor, temperature-dependent Kcarb/KCO₂, gas exchange, turnover and source pools. The signs and numerical coefficients match. | Correct five-pool source adaptation. Fossil carbon is external; land-use burning and soil disruption redistribute existing carbon. Volcanic 0.6 and burial 0.6 cancel globally. Cumulative anthropogenic emissions count both fossil input and land redistribution, so they appropriately differ from the total physical-pool increase. The respiration alias is explicitly reporting-only, with one physical vegetation debit. |
| Ocean heat | Freshly retrieved [FaIR 2.1.0 native operator](https://raw.githubusercontent.com/OMS-NetZero/FAIR/v2.1.0/src/fair/energy_balance_model.py); SHA-256 exactly matches the fixture. Checked `_eb_matrix`, deterministic examples and `toa_imbalance`. Converted its temperature-coordinate matrix independently to heat coordinates. | Correct efficacy placement: the intermediate layer loses efficacy times the deep exchange while the deep layer receives the unscaled exchange. The separately represented `(efficacy−1)*exchange` external flux is required by the native energy budget. Surface temperature is consistently redundant with surface heat/capacity. Local forcing remains an explicitly declared experiment. |
| Phosphorus lake | Freshly retrieved the pinned [MyLake 1.2 parameter workbook](https://raw.githubusercontent.com/biogeochemistry/MyLake_public/d882070870bd0bd541376ee8b627282d3ae8d329/v12/Vansjo_application/VAN_para_v12.xls); hash matches. Parsed `lake!B35=1`, row label `Y_cp`. Read [native source](https://raw.githubusercontent.com/biogeochemistry/MyLake_public/d882070870bd0bd541376ee8b627282d3ae8d329/v12/v12/solvemodel_v12.m), parameter unpacking, initial P check, net biological rate and matching phosphorus debit. | Yield direction is correct: Y_cp is chlorophyll/P, so nutrient debit is algal growth/Y_cp. The native net-growth coupling also credits P when algal net growth is negative; separating growth and mortality into matched uptake/recycling preserves that identity. Sediment concentration uses water-volume equivalence, so no sediment-volume conversion is silently omitted in this reduced model. Existing anoxia and growth kinetics remain declared local assumptions. |
| Solar irradiance | Freshly retrieved the [NRLTSI2 annual CSV](https://lasp.colorado.edu/lisird/latis/dap/nrl2_tsi_P1Y.csv); hash matches. Independently converted days since 1610-01-01 and compared all **173** values in the 1849–2021 fixture exactly. Checked the [FaIR two-layer calibration](https://docs.fairmodel.net/en/v2.1.0/examples/n-layer-ebm.html). | Correct absorbed anomaly `(1−albedo)*ΔTSI/4`, heat-capacity division, feedback and efficacy. Raw annual timestamps are July 1; the implementation deliberately assigns annual means to integer calendar years. That is a disclosed annual-forcing convention, not preservation of exact native timestamps. Signed deep heat is an anomaly, not negative absolute energy. |
| World3 resources | Read the pinned [resource.py standalone closure](https://raw.githubusercontent.com/cvanwynsberghe/pyworld3/cdfd0a8f3675c514f27ddc0e00c8d8bd4d1fefb8/pyworld3/resource.py), especially `init_exogenous_inputs`, update ordering and table interpolation endpoint behavior. | Capital investment/depreciation, population closure and resource usage map to the native standalone example. The source's population switch at year 2500 does not affect the preserved 1900–2100 horizon. This is properly scoped as a standalone-sector demonstration, not a coupled World3 run. |
| Beer game | Read the complete cached native `RB4-S13-NoSS-6.mdl`; its byte hash matches the recorded native hash. Checked order rounding, desired/effective stock and supply line, one-week queues, shipment/backlog accounting and the `.26/.34/.25` policy coefficients. Fresh archive retrieval was unavailable, so this check uses the hash-verified native cache. | The explicit graph and independent weekly replay match the native autonomous policy. The source is a weekly difference system. Root/A identified and are enforcing `discrete_period=1`; fractional-grid runs must not be presented as source board-game replications. Native initial week 1 and horizon 36 differ from the explicitly preserved local 0–52 clock. |

The physical mappings above are supported by direct primary-source checks, rather than by finite output alone. Existing A tests independently exercise matrix evolution, nutrient/carbon budgets and full-horizon reference integrations. No additional test duplicating those checks was added.

Remaining scope is visible in the model descriptions: the solar amplitude/period/sensitivity controls and several old carbon/ocean controls are retained but do not alter the restored source operators; the experiments do not include every native stochastic, geographic or clinical feature. Those limitations should remain visible in any public release description.
