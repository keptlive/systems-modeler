# Two isolated engineering candidates

Research only. No active model, runtime, public catalog, database, API or remote changes. Future adoption needs root authorization and independent review of the exact frozen hashes. Existing public catalog baseline is996.

**Finite-source machine repair** models three machines and one repairer through four ensemble probability states. It supports expected downtime, availability, queue waiting and repairer utilization. Independent exponential failure clocks run only for operating machines; a single repairer handles all down machines sequentially. The finite population and full probability distribution distinguish it from the catalog busy-line/blocked-call Erlang fluid approximation and M/M/1 mean queue. State topology is fixed; no editable population variable pretends to resize the chain. Nonnegative rates, normalized nonnegative initial probabilities; time hours. Defaults failure.2/hour, repair1/hour, initially all working, RK4 dt.02 end30. Not event sampling, a reliability estimate from measured data, common-cause failures or aging.

**PI back-calculation** couples a signed integral actuator contribution and normalized first-order output. Saturation is an explicit modeled actuator bound; tracking feeds actual-minus-command into the integral. It demonstrates windup and recovery, unlike the catalog Wiener model whose error accumulator does not feed the plant, grid governor proportional droop, or pendulum state feedback. Defaults reference.8, Kp3, Ki1/second, tracking2/second, plant gain1/time2seconds, bounds0..1; zero initial states, RK4 dt.01 end20. Plant time must be positive; gains nonnegative, lower bound strictly below upper. States/signals dimensionless, time seconds. No delay, derivative action, rate limits or universal tuning guarantee. Zero tracking disables anti-windup. Negative integral values are expected.
