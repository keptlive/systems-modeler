To try a case, open Inspect, select r under Equations & initial values, change its Equation in the existing editor, then Run. This intentionally changes the current draft; Save is separate. To compare, run and Save Run for 3.7, then 3.8, then 3.9 and use Compare; generated run labels follow that order, so retain parameter notes/exports. Former May's Logistic Map Model (may-logistic-chaos,r=3.7) and May Ecological Chaos Model (may-ecological-chaos-eco,r=3.8) are these parameter cases, not separate mechanisms. Agents can use compare_scenarios with model_id may-chaos-population-eco and named parameters r/Population; use the published preset payload when available.
